# Security policy

The cosigner must sign only a log it has verified: a continuous hash chain, a tree it
computed itself, and entry times within its own observations. A way to make it sign anything
else, to read or derive its private key, or to make it sign a backdated entry is a
vulnerability. Please report it privately by e-mail to **kontakt@advena-partners.com**
(English, German or Polish), as listed in <https://sigelith.org/.well-known/security.txt>,
and do not open a public issue for it.

Fixes are released as a new image and Lambda package; only the latest release is supported.
